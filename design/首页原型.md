# 汐序首页原型

2026-10-31：uni-app Vue 3 首页已在 Android 真机运行。真机截图：`首页原型-真机-2026-10-31.png`。

## 页面结构

1. 品牌与当前日期、问候语。
2. 今日一览：今日支出、待办日程、生活记录数量。
3. 快速入口：记一笔、看日程、写日志、存附件。
4. 今日片段：按时间排列课程、账目等记录。

## 当前边界

- 日期与问候语取设备当前时间。
- 金额、数量、课程和账目均为**示例数据**，页面已明确标注；没有读取 dsh-im 的私人记录。
- 快速入口目前只显示“页面正在制作”提示，尚无录入、存储或跳转功能。
- 此阶段只有首页原型。数据库设计时从上述信息和完整业务用例推导字段，不直接按页面卡片凑表。
