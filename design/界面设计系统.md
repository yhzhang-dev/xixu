# 汐序界面设计系统 v1

参考 [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) 中的 Productivity Tool、Minimalism & Swiss Style 与触控/表单规则，结合汐序现有图标和真实业务页面制定。自动生成器的深色玻璃金融看板、英文手写字体与本项目不匹配，因此未直接套用。

## 设计定位

安静、可信、便于反复使用的个人手账。数据优先于装饰；真实记录与尚在开发的模块要清楚区分。Web 负责回看和整理，手机负责快速记录与当天概览。

## 共用视觉变量

| 语义 | 色值 | 使用位置 |
|---|---|---|
| 背景 | `#F5F7F4` | 页面底色 |
| 纸面 | `#FFFFFF` | 卡片、表单、列表 |
| 主文字 | `#173D46` | 标题、关键数据 |
| 次文字 | `#567077` | 正文、说明 |
| 品牌色 | `#17675F` | 主按钮、选中态 |
| 品牌深色 | `#103E48` | Web 侧栏、登录主视觉 |
| 浅品牌色 | `#E7F2ED` | 轻量选中背景 |
| 分隔线 | `#DAE6E1` | 控件边框、卡片边界 |
| 支出 | `#A75543` | 支出数值、作废提示 |

中文文字使用系统无衬线字体，数字使用等宽数字特性。屏幕标题、卡片标题、正文和辅助说明分别约为 28–32、17–20、14–16、12–13 CSS px；移动端按 rpx 等比实现并核对真机可读性。间距主要使用 8、16、24、32 的节奏，手机操作目标以 Android 48dp 为基准。

## 页面结构

- Web：固定侧栏 + 顶部当前页 + 内容区。总览显示真实的今日账目和日志，并提供两条主要入口；未上线模块独立展示进度。表单与列表按任务分区，窄屏改为纵向布局。
- 手机：紧凑品牌栏 + 今天的真实概览 + 快速记录与回看入口 + 最近账目；列表页突出筛选、状态和内容。固定的列表快捷按钮避开系统手势区域。
- 登录：共用品牌色和文字层级。表单标签常驻，错误信息紧邻表单，密码可显隐。

## 交互规则

- 假数据只在明确标注的演示区出现；不把未完成模块呈现成可操作入口。
- 主要操作有按下、加载、成功和失败状态；错误保留用户输入。
- Web 键盘焦点可见，图标按钮有文本标签。手机操作区域尽量不小于 48dp，固定按钮考虑底部安全区。
- 减少装饰性渐变和轨道圆环；动效只反馈状态，不妨碍阅读。
