# 汐序应用图标

当前采用 [第二版图标](汐序图标-v2.png)：用翻起的纸页、潮线和一个圆点表达「记录一天」与「汐」。青绿色延续登录页和 Web 工作台的颜色。旧版大字图标及其导出文件已按用户要求删除。

Android 图标资源位于 `android/static/app-icons/v2/`，包含 48、72、96、144、192 和 1024 像素 PNG。`android/manifest.json` 已在 `app-plus.distribute.icons.android` 映射到对应尺寸；Web 页签图标也已换成相同设计。

HBuilderX 标准真机运行基座使用 DCloud 的包名与桌面图标。要在手机桌面看到「汐序」自己的图标，需要使用**自定义调试基座**或打包安装独立 APK；改 `manifest.json` 后不会让标准基座的绿色 H 图标立即变化。正式打包尚未执行。
