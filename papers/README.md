# 论文存放目录

把要分析的论文放在这个目录里即可，PDF、CAJ、HTML 存档都行，也可以直接放 URL 清单（`urls.txt`，一行一个链接）。

## 文件命名（建议，非强制）

`作者-年份-短标题.pdf`，例如：

- `Li-2010-Stage-Based-Model-Personal-Informatics.pdf`
- `Epstein-2015-Lived-Informatics.pdf`
- `张三-2023-个人健康数据管理综述.pdf`

原始文件名（如从知网下载的 `CNKI_xxxx.pdf`）也能用，我会打开文件读首页识别标题、作者和年份，再登记到索引里。

## 我会做什么

1. 逐篇读取，提取标题、作者、年份、期刊／会议、摘要与核心结论。
2. 在 [00-索引.md](00-索引.md) 里登记一行，标注所属方向（A 个人数据管理 / B 同类系统 / C 技术取舍 / D 跨端与建模 / E 智能助理）。
3. 按 `paper-write` 的文献卡片格式写进 `thesis/11-文献/`，最后汇总为 GB/T 7714 格式的参考文献表。

## 注意

- 有版权的 PDF / CAJ 只在本机工作区使用；根目录 `.gitignore` 已忽略 `papers/*.pdf` 与 `papers/*.caj`，索引与说明仍会入库。
- 涉及个人隐私的数据（真实账目、健康记录截图）不要放进这里。
