## 动笔前必须确认的五件事

1. **题目副标题怎么处理**。现题目承诺“自然语言与图像识别”，代码中没有模型调用。保留则须在中期前补最小闭环，去掉则须在开题前改题。两条路都要教师点头。
2. **学校论文模板**：章节编号（是否用“第 1 章”）、字号行距、图表编号与标题位置、页眉页脚、参考文献样式。
3. **字数要求**：学校或教师是否给了下限。本工作区目前按 1.8 万–2.2 万字排布各章配额。
4. **查重口径**：学校用何系统、阈值多少，决定第 1、2 章的综述写法。
5. **外文翻译的具体要求**：篇数、字数、是否需附原文。
