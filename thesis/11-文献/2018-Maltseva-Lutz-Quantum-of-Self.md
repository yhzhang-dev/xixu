## 二、研究问题

1. 哪些人格特质与自我量化（self-quantification）相关？
2. 隐私顾虑与制度信任在量化过程中起什么作用？"隐私悖论"是否成立？
3. 习惯性自我量化会不会让人在**与量化无关的其他场景**中也更愿意披露个人信息？

## 三、方法

- 2016 年 10 月通过 Amazon Mechanical Turk（TurkPrime）发放问卷，Qualtrics 编程，约 10 分钟，报酬 1.5 美元 + 0.5 美元奖励。
- 475 人填写，24 人（5.1%）未通过注意力检测被剔除，余 451 人；410 人进入 SEM。
- 样本：男性 52.4%，平均年龄 33.3 岁（18–70），教育程度分布较广。
- 自我量化的测量：依据 Li 等（2010）的 PI 阶段模型自编 15 题（采集 / 反思 / 行动），因子分析后保留 5 题。
- 自我披露的测量：不用自评，而是**行为式**——12 个敏感度不同的个人信息问题（关系、人格、人口学、财务、健康、教育），回答记 1 分、选"不愿回答"记 0 分，累加 0–12；再让受访者对每题敏感度打 0–100 分。
- 隐私顾虑、制度信任、大五人格均用量表；SEM 估计。

## 四、主要结果

| 结论 | 统计量 |
|---|---|
| 样本的自我量化程度偏高 | 均值 3.87/5 |
| 隐私顾虑偏高 | 均值 3.88/5 |
| **尽责性是最强驱动** | β = 0.42，p < 0.001 |
| **情绪稳定性越低，越常量化** | β = -0.25，p = 0.009 |
| 外向性、宜人性、开放性不显著 | p = 0.071 / 0.709 / 0.714 |
| **隐私顾虑高的人反而更多自我量化**（反直觉） | β = 0.25，p < 0.001 |
| 隐私顾虑降低制度信任 | β = -0.31，p < 0.001 |
| 制度信任高的人更多自我量化 | β = 0.17，p = 0.003 |
| **自我量化显著提高自我披露** | β = 0.13，p = 0.019 |
| 信息敏感度强烈抑制披露 | β = -0.37，p < 0.001 |
| 解释力 | 披露 R² = 16%，量化 R² = 19% |

模型拟合：RMSEA 0.035、CFI 0.97、TLI 0.96、SRMR 0.048，可接受。年龄、性别、教育均不显著。

**敏感度排序（0–100，均值）**：性伴侣 61 > 存款 60 > 信用卡负债 54 > …… > 最喜欢的科目、身高、耐心（中位数低于 10）；总均值 35。

> 注意：摘要里的措辞是"情绪稳定性与尽责性与自我量化相关"，但系数是**负的**——情绪越不稳定，越常量化。引用时不要写成"情绪稳定者更爱记录"。

## 五、作者的解释与主张

- **实践建议**：开发者应从"社区导向"的量化体验转向"自我导向"（selfhood-oriented）的体验，给用户更多反思与理解自己数据的机会。
- **隐私悖论成立**：隐私顾虑并不降低披露行为，说明"告知隐私政策"作用有限。
- **一个尖锐的问题**：自我量化者究竟是因此获得了对生活的控制，还是因为披露更多而**失去了控制**？

## 六、局限（引用时必须交代）

- 横断面问卷，只能说相关，不能推因果。
- MTurk 样本，非概率抽样，不能外推到一般人群（更不能直接外推到中国用户）。
- 除自我披露外缺乏行为数据；大五人格用短量表。
- 解释力偏低（R² 16%–19%），效应量小（如 β = 0.13），不宜夸大。
- 未区分追踪的具体领域（饮食、情绪、关系等）。

## 七、与本项目的关系

### 能支撑的设计判断

| 论文章节 | 用法 |
|---|---|
| 2.1.3 非功能性需求 | 本系统的数据（收支、体重、睡眠）正落在本文测得的**高敏感类别**（存款 60、负债 54）；隐私不是"顺便提一句"，而是需求 |
| 3.1 设计原则 | 支撑"数据归属单一原则"：所有读写按令牌解析的 user_id 限定，客户端不能代传他人 ID |
| 3.2 / 3.5 安全设计 | 支撑"不做社交分享、不引入第三方 SDK、不上云"的取舍；隐私悖论说明结构性控制优于政策告知 |
| 4.2 认证实现 | 令牌只存 SHA-256 摘要、会话上限 5 个、退出即失效，属于"结构性控制"，可与本文的隐私悖论呼应 |
| 6.2 展望 | 数据导出、可见范围控制、注销与清空，是本文实践建议的自然延伸 |

### 不能支撑的地方

- 不提供任何技术方案或架构依据。
- 不能用来论证"用户一定会用你的系统"——它是横断面相关研究，不是可用性测试。
- 样本是美国 MTurk 用户，写"国内用户同样如此"属于过度外推。

## 八、可直接引用的原句（译）

- "习惯性使用自我追踪应用与可穿戴设备的人，在其他情境下也更可能披露个人数据。"（摘要）
- "隐私顾虑并不会导致更少的自我披露。"（4．结果）
- "自我量化者究竟因此获得了对生活的控制，还是因为披露更多而失去了控制？"（5.1）
- "开发者或许应当把重心从社区导向的量化体验，转向自我导向的体验。"（5.2）

## 九、读后立刻可做的一件事

本文最实用的一条是"敏感度决定披露意愿"。本系统当前**没有数据导出、没有注销**，用户对数据的可控感完全依赖"我相信作者"。
补一个导出接口（三张表拼 JSON）约 1–2 小时，却能把 3.5 节从"我们用了令牌"提升到"用户对数据有实际控制权"。
