## 五、核心接口清单（共 17 个）

| 方法 | 路径 | 说明 | 来源 |
|---|---|---|---|
| GET | `/api/health` | 健康检查 | `HealthController` |
| POST | `/api/auth/login` | 登录，返回令牌与用户信息 | `AuthController` |
| GET | `/api/auth/me` | 当前登录用户 | 同上 |
| POST | `/api/auth/logout` | 退出，撤销令牌 | 同上 |
| POST | `/api/ledger/entries` | 新增账目，服务端固定 `sourceType=手动` | `LedgerController` |
| GET | `/api/ledger/entries` | 分页查询，支持日期区间与 `includeVoided` | 同上 |
| GET | `/api/ledger/entries/{id}` | 单条查询 | 同上 |
| GET | `/api/ledger/summary` | 汇总有效记录的收入、支出、笔数 | 同上 |
| POST | `/api/ledger/entries/{id}/void` | 带原因作废，重复作废返回 409 | 同上 |
| POST | `/api/logs` | 新增日志或训练（含组次，同一事务） | `LogController` |
| GET | `/api/logs` | 分页查询，支持 `type`/`from`/`to` | 同上 |
| GET | `/api/logs/{id}` | 单条记录及组次 | 同上 |
| GET | `/api/wellness/body` | 体重与体成分查询 | `WellnessController` |
| POST | `/api/wellness/body` | 体重与体成分新增 | 同上 |
| GET | `/api/wellness/sleep` | 睡眠记录查询 | 同上 |
| POST | `/api/wellness/sleep` | 睡眠记录新增 | 同上 |
| GET | `/api/assistant/tools/monthly-snapshot` | 只读月度跨模块汇总 | `AssistantToolController` |

除 `/api/health` 与 `/api/auth/login` 外，所有接口要求 `Authorization: Bearer <token>`；数据归属一律由令牌解析出的 `user_id` 限定，客户端不可代传他人 ID。

## 七、运行方式（论文“系统实现”与附录可引用）

1. 启动 MySQL 服务 `MySQL84`（随 Windows 自启）。
2. `cd server && .\start-local.ps1`，按提示输入本地 MySQL 凭据，端口 18080。
3. `cd admin && npm run dev`，浏览器访问 `http://127.0.0.1:5173/`。
4. Android 真机：HBuilderX 运行到手机，配合 `adb reverse` 把手机 `127.0.0.1:18080` 转发到本机。
