# 本地建库建表：第一步

本项目先在本机 MySQL 8.4 建开发库 `xixu_dev`，目前只创建 `app_user` 表。SQL 文件是 [`schema.sql`](schema.sql)。**尚未执行**；执行后以 MySQL 的查询结果为准。

## 1. 打开 MySQL 命令行

在 PowerShell 输入：

```powershell
& "C:\Program Files\MySQL\MySQL Server 8.4\bin\mysql.exe" --default-character-set=utf8mb4 -h 127.0.0.1 -P 3306 -u root -p
```

看到 `Enter password:` 后输入安装 MySQL 时设置的 root 密码。密码输入时不显示字符；不要把密码写在命令中或发到聊天里。成功后会看到 `mysql>` 提示符。以下命令均在 `mysql>` 中逐行执行。

## 2. 创建并选中开发数据库

```sql
CREATE DATABASE xixu_dev CHARACTER SET utf8mb4 COLLATE utf8mb4_0900_ai_ci;
USE xixu_dev;
SELECT DATABASE();
```

最后一条应返回 `xixu_dev`。若第一条提示数据库已存在，先不要删除或重建，检查已有库再决定如何继续。

## 3. 创建第一张表

```sql
SOURCE E:/graduation-project/database/schema.sql
```

正常应看到 `Query OK`。路径使用正斜杠；`SOURCE` 是 MySQL 客户端命令，不是在 PowerShell 中输入。

## 4. 检查结果

```sql
SHOW TABLES;
DESCRIBE app_user;
SHOW CREATE TABLE app_user\G
SELECT COUNT(*) FROM app_user;
```

应看到 `app_user`，包含 `id`、`username`、`password_hash` 等字段；记录数应为 0。尚未实现服务端密码哈希及账号初始化，所以暂不手工插入用户或明文密码。完成后输入 `exit` 退出 MySQL。

如遇错误，保留**错误文字和执行到第几步**即可；不要发送密码。切勿用 `DROP DATABASE`、`DROP TABLE` 或覆盖已有结构来处理错误。

## 后续

先完成用户表和登录接口，再根据记账等业务设计新增表。`schema.sql` 是当前结构草案，不用于对已有数据库反复执行；后续结构变更应另存迁移脚本。云端部署时创建独立数据库并执行经过验证的建表或迁移脚本，再按需迁移真实数据。
