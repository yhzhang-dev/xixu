## 核对记账表

在已连接 `xixu_dev` 的 MySQL 客户端执行以下**只读**语句：

```sql
SHOW TABLES;
DESCRIBE ledger_entry;
SHOW CREATE TABLE ledger_entry\G
SELECT COUNT(*) FROM ledger_entry;
```

正常应看到 `ledger_entry`，含 `entry_type`、`amount`、`occurred_on`、`status`、`void_reason` 等字段。记录数取决于是否已有账目，不要求为 0。若表不存在，再按[建表脚本](04-记账表建表.sql)处理；不要在已建表时重复执行。遇错保留错误文字即可，不要发送密码。
