## VS Code 中打开工程

按 [VS Code 配置 Spring Boot](VS-Code配置Spring-Boot.md) 打开 `server/` 并检查 Java 项目导入。扩展已装齐，无需重复安装。

## 可选

- **MySQL Workbench**：图形化连接数据库、画 ER 图和检查 SQL。官方下载：https://dev.mysql.com/downloads/workbench/ 。也可以先用 Markdown/Mermaid 讨论 ER 图，不强制安装。
- **IntelliJ IDEA**：若更习惯用专门的 Java IDE，可用于后端开发；目前 VS Code 加上述扩展即可开始。官方下载：https://www.jetbrains.com/idea/download/ 。
